مرتب‌سازی ادغامی با درخت بازگشت

درخت بازگشت و سریدر جزوه: بخش ۲.۳، رابطهٔ بازگشتی و درخت بازگشت ↗

برای \(n\) توانی از ۲، رابطهٔ \(T(n) = 2T(n/2) + n\) با \(T(1) = 0\) جواب \(T(n) = n\log_2 n\) دارد؛ پس زمان مرتب‌سازی ادغامی \(O(n\log n)\) است.

اثبات در حالت تمرین، اول خودتان امتحان کنید
اثبات با درخت بازگشت

هزینهٔ هر سطح: سطح \(k\) (ریشه سطح ۰ است) \(2^k\) زیرمسئله به اندازهٔ \(n/2^k\) دارد و ادغام هر کدام \(n/2^k\) کار می‌برد: \(\;2^k \cdot \frac{n}{2^k} = n\).

تعداد سطح‌ها: اندازه در هر سطح نصف می‌شود و از \(n\) به ۱ می‌رسد؛ پس \(\log_2 n\) سطح هزینه‌دار داریم (برگ‌ها، یعنی زیرمسئله‌های یک‌عنصری، هزینه‌ای ندارند).

جمع: \(\;T(n) = \underbrace{n + n + \dots + n}_{\text{بار}\;\log_2 n} = n\log_2 n.\)

قضیهٔ اصلی (حالت \(f(n) = O(n^d)\))

درخت بازگشت و سریدر جزوه: بخش ۲.۵، قضیهٔ اصلی ↗

قضیهٔ اصلی برای \(f(n) = O(n^d)\)
\[T(n) = a\,T\!\left(\frac nb\right) + O(n^d) \quad\Longrightarrow\quad T(n) = \begin{cases} O(n^d\log n) & \log_b a = d\\ O(n^d) & \log_b a < d\\ O(n^{\log_b a}) & \log_b a > d\end{cases}\]
اثبات در حالت تمرین، اول خودتان امتحان کنید
چرا این سه حالت؟ (سری هندسی)

هزینهٔ سطح \(k\) حداکثر \(a^k \cdot c\left(\frac{n}{b^k}\right)^d = c\,n^d\left(\frac{a}{b^d}\right)^k\) است. پس کل هزینه یک سری هندسی با قدرنسبت \(r = a/b^d\) است:

\[T(n) \le c\,n^d \sum_{k=0}^{\log_b n} r^k.\]
  • \(r < 1\) (یعنی \(a < b^d\)، یعنی \(\log_b a < d\)): سری نزولی است و جمعش حداکثر \(\frac{1}{1-r}\)، یک ثابت. پس \(T(n) = O(n^d)\): ریشه غالب است.
  • \(r = 1\) (یعنی \(\log_b a = d\)): همهٔ \(\log_b n + 1\) جمله برابر ۱ هستند. پس \(T(n) = O(n^d\log n)\).
  • \(r > 1\) (یعنی \(\log_b a > d\)): سری صعودی است و جمعش هم‌مرتبهٔ آخرین جمله است: \(r^{\log_b n} = \frac{a^{\log_b n}}{(b^{\log_b n})^d} = \frac{n^{\log_b a}}{n^d}\). ضرب در \(n^d\): \(T(n) = O(n^{\log_b a})\): برگ‌ها غالب‌اند.

جمع دبستانی بهینه است

استدلال مستقیمدر جزوه: بخش ۲.۸، جمع و ضرب اعداد صحیح ↗

هر الگوریتمی که دو عدد صحیح \(n\)بیتی را جمع کند، در بدترین حالت \(\Omega(n)\) زمان لازم دارد؛ بنابراین روش جمع دبستانی (\(O(n)\)) بهینه است.

اثبات در حالت تمرین، اول خودتان امتحان کنید

هر الگوریتم جمع باید دست‌کم همهٔ \(2n\) بیت ورودی را بخواند (تغییر هر بیت، جواب را تغییر می‌دهد)، پس \(\Omega(n)\) زمان لازم است. روش دبستانی \(O(n)\) است، پس بهینه است.

حل \(T(n) = 2T(n/2) + n\) با حدس و استقرا

استقرادر جزوه: بخش ۲.۱۰، روش حدس و استقرا ↗

اگر \(T(1) = 1\) و برای \(n\) توانی از ۲، \(T(n) = 2T(n/2) + n\)، آنگاه \(T(n) = n(\log n + 1)\).

اثبات در حالت تمرین، اول خودتان امتحان کنید

فرض استقرا: \(T(n) = n(\log n + 1)\).

پایه (\(n=1\)): \(T(1) = 1 = 1\cdot(\log 1 + 1)\). ✓

گام: فرض کنید حکم برای همهٔ \(1 \le n < k\) برقرار است. آنگاه

\[T(k) = 2\,T(k/2) + k = 2\cdot\frac k2\left(\log\frac k2 + 1\right) + k = k\,(\log k - 1 + 1) + k = k(\log k + 1).\]

(خط اول تعریف \(T\)، تساوی دوم فرض استقرا برای \(k/2 < k\)، و بقیه ساده‌سازی است.) پس حکم برای \(n = k\) هم برقرار است.

نتیجه: برای همهٔ \(n \ge 1\) (توان ۲)، \(T(n) = n(\log n + 1) = O(n\log n)\).

استقرا با ثابت نامعلوم: \(T(n) = 2T(n/2) + 32n\)

استقرادر جزوه: بخش ۲.۱۰، روش حدس و استقرا ↗

اگر \(T(2) = 2\) و برای \(n\) توانی از ۲، \(T(n) = 2T(n/2) + 32n\)، آنگاه برای همهٔ \(n \ge 2\): \(T(n) \le 32\,n\log n\)؛ یعنی \(T(n) = O(n\log n)\).

اثبات در حالت تمرین، اول خودتان امتحان کنید

حدس: \(T(n) \le C\cdot n\log n\) برای ثابتی مثل \(C\) که هنوز نمی‌دانیم.

پایه: \(T(2) = 2 \le C\cdot 2\log 2 = 2C\)، که برای \(C \ge 1\) برقرار است.

گام: فرض کنید برای \(n < k\) برقرار باشد. آنگاه

\[\begin{aligned} T(k) &= 2\,T(k/2) + 32k \;\le\; 2C\,\frac k2\log\frac k2 + 32k\\ &= Ck(\log k - 1) + 32k \;=\; Ck\log k + (32 - C)\,k\\ &\le Ck\log k \qquad C \ge 32\;\;\text{به شرط} \end{aligned}\]

پس با \(C = 32\) (که شرط پایه را هم دارد) حکم برقرار است.

فرض استقرا: \(T(n) \le 32\,n\log n\). پایه: \(T(2) = 2 \le 32\cdot2\log2\). ✓

گام: برای \(n < k\) فرض را داریم. \(T(k) = 2T(k/2) + 32k \le 2\cdot32\cdot\frac k2\log\frac k2 + 32k = 32k(\log k - 1) + 32k = 32\,k\log k\).

نتیجه: برای همهٔ \(n \ge 2\)، \(T(n) \le 32\,n\log n\). طبق تعریف \(O\) با \(n_0 = 2\) و \(c = 32\)، \(T(n) = O(n\log n)\).

دو زیرمسئلهٔ نابرابر: \(T(n/5) + T(7n/10) + n\)

استقرادر جزوه: بخش ۲.۱۰، روش حدس و استقرا ↗

اگر برای \(1 \le n \le 10\)، \(T(n) = 1\) و برای \(n > 10\)، \(T(n) \le T(n/5) + T(7n/10) + n\)، آنگاه برای همهٔ \(n \ge 1\): \(T(n) \le 10n\).

اثبات در حالت تمرین، اول خودتان امتحان کنید
گام ۲: \(C\) را در طول اثبات پیدا می‌کنیم

فرض استقرا: \(T(n) \le C\,n\). پایه: \(1 = T(n) \le Cn\) برای \(1 \le n \le 10\)؛ کافی است \(C \ge 1\).

گام: برای \(k > 10\) و فرض برقرار برای \(1 \le n < k\):

\[T(k) \le k + C\cdot\frac k5 + C\cdot\frac{7k}{10} = k + \frac{9C}{10}\,k \;\overset{?}{\le}\; C\,k.\]

نامساوی آخر یعنی \(k \le \frac{C}{10}k\)، یعنی \(C \ge 10\). پس \(C = 10\) کار می‌کند: \(\;T(k) \le k + 2k + 7k = 10k\).

نتیجه: برای همهٔ \(n \ge 1\)، \(T(n) \le 10n\)؛ یعنی \(T(n) = O(n)\) با \(n_0 = 1\) و \(c = 10\).

رابطه‌های دو شاخه‌ای

درخت بازگشت و سریاستقرادر جزوه: بخش ۲.۱۰، روش حدس و استقرا ↗

رابطه‌های دو شاخه‌ای
\[T(n) \le T(an) + T(bn) + O(n) \;\Longrightarrow\; T(n) = \begin{cases} O(n) & a + b < 1\\ O(n\log n) & a + b = 1\end{cases}\]
اثبات در حالت تمرین، اول خودتان امتحان کنید

شهود با درخت بازگشت: اگر ریشه \(cn\) کار کند، دو فرزندش \(c(an) + c(bn) = (a+b)\,cn\) کار می‌کنند، نوهٔ‌ها \((a+b)^2cn\) و ... . اگر \(a + b < 1\)، این یک سری هندسی نزولی است با جمع حداکثر \(\frac{cn}{1-(a+b)} = O(n)\). اگر \(a+b = 1\)، هر سطح حداکثر \(cn\) کار دارد و عمق درخت \(O(\log n)\) است.

اثبات استقرایی حالت اول: با فرض \(T(n) \le Cn\): \(T(k) \le Cak + Cbk + ck = Ck(a+b) + ck \le Ck\) اگر \(C \ge \frac{c}{1 - a - b}\).

حالت دوم: مثل اثبات کادر قبل؛ با فرض \(T(n) \le Cn\log n\) به شرط \(C \ge c/H\) می‌رسیم که \(H = a\log\frac1a + b\log\frac1b > 0\).

تقویت فرض استقرا: \(T(n) \le 2T(n/2) + 1\)

استقرادر جزوه: بخش ۲.۱۰، روش حدس و استقرا ↗

اگر \(T(1) = 1\) و برای \(n \ge 2\) (توان ۲)، \(T(n) \le 2T(n/2) + 1\)، آنگاه \(T(n) \le 2n - 1\)؛ یعنی \(T(n) = O(n)\).

اثبات در حالت تمرین، اول خودتان امتحان کنید
فرض قوی‌تر: یک جملهٔ مرتبه‌پایین کم کن

فرض استقرا: \(T(n) \le Cn + B\) (که \(B\) می‌تواند منفی باشد). پایه: \(1 = T(1) \le C + B\).

گام:

\[T(k) \le 2\left(C\frac k2 + B\right) + 1 = Ck + 2B + 1 \;\overset{?}{\le}\; Ck + B \iff B \le -1.\]

با \(B = -1\)، پایه \(C \ge 2\) می‌خواهد. پس حدس جدید \(T(n) \le 2n - 1\) با استقرا ثابت می‌شود.
