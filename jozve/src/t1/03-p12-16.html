شمارهٔ ستون

سختتقسیم و حلآرایهٔ مونژجزوه: فصل ۲

چرا «سخت»؟ سه ایده لازم است: اثبات یکنوایی \(f\)، الگوریتم «سطرهای زوج بازگشتی» و تحلیل تلسکوپی آن.

ایده‌های این مسئله در ایده‌نامه: ۲.۱۷ جای بهترین جواب یکنواست

آرایهٔ دوبعدی \(A\) به ابعاد \(m \times n\) از اعداد حقیقی داده شده و برای هر \(i < k \le m\) و \(j < l \le n\):

\[A[i, j] + A[k, l] \le A[i, l] + A[k, j].\]

برای سطر \(i\)، شمارهٔ ستون چپ‌ترین عدد کمینهٔ آن سطر را \(f(i)\) می‌نامیم. الگوریتمی از مرتبهٔ \(O(m + n\log m)\) ارائه دهید که \(f(i)\) را برای همهٔ سطرها پیدا کند.

اول ثابت کنید \(f(1) \le f(2) \le \dots \le f(m)\): اگر برای یک \(i\) داشته باشیم \(f(i) > f(i+1)\)، شرط مسئله را برای سطرهای \(i\) و \(i+1\) و ستون‌های \(f(i+1)\) و \(f(i)\) بنویسید و به تناقض برسید. حالا اگر \(f\) سطرهای زوج را (بازگشتی) بدانیم، کمینهٔ هر سطر فرد بین ستون‌های دو همسایهٔ زوجش است.

تقسیم و حل نامتقارن

در تقسیم و حل لازم نیست دو نیمه شبیه هم باشند. این‌جا نیمهٔ «زوج» را بازگشتی حل می‌کنیم و نیمهٔ «فرد» را با استفاده از جواب نیمهٔ اول، مستقیم و ارزان. رابطهٔ زمانی شکل \(T(m) = T(m/2) + O(m + n)\) پیدا می‌کند. شرط مسئله را شرط مونژ ({{Monge}}) می‌گویند.

۱یکنوایی \(f\)

فرض خلف: \(f(i) > f(i+1)\). بگذارید \(j = f(i+1)\) و \(l = f(i)\)، پس \(j < l\). شرط مونژ برای سطرهای \(i < i+1\) و ستون‌های \(j < l\): \(A[i, j] + A[i+1, l] \le A[i, l] + A[i+1, j]\).

  • چون \(l\) چپ‌ترین کمینهٔ سطر \(i\) است و \(j < l\)، داریم \(A[i, j] > A[i, l]\) (اکید).
  • چون \(j\) کمینهٔ سطر \(i+1\) است، \(A[i+1, j] \le A[i+1, l]\).

جمع این دو: \(A[i, j] + A[i+1, l] > A[i, l] + A[i+1, j]\)، که با شرط مونژ تناقض دارد. پس \(f(1) \le f(2) \le \dots \le f(m)\).

۲زیرآرایه هم مونژ است

اگر فقط بعضی سطرها (مثلاً سطرهای زوج) را نگه داریم، هر \(i < k\) و \(j < l\) در زیرآرایه در آرایهٔ اصلی هم هست، پس شرط برقرار می‌ماند. یعنی می‌توان روی سطرهای زوج بازگشت زد.

۳الگوریتم

if k == 1
    return leftmost minimum of row r1 over columns 1..n
f = MONGE-MIN(A, r2, r4, r6, ...)        // recurse on the even positions
for t = 1, 3, 5, ... (t <= k)
    lo = 1 if t == 1 else f[r(t-1)]
    hi = n if t == k else f[r(t+1)]
    f[rt] = leftmost minimum of row rt over columns lo..hi
return f

درستی: طبق یکنوایی، \(f(r_{t-1}) \le f(r_t) \le f(r_{t+1})\)، پس جست‌وجو در بازهٔ \([lo, hi]\) کافی است. اگر چند کمینه در این بازه بود، چپ‌ترینش چپ‌ترین کمینهٔ کل سطر هم هست (کمینهٔ کمتر از آن قبل از \(lo\) وجود ندارد).

۴تحلیل زمان

هزینهٔ پیمایش سطرهای فرد، با \(f(r_0) = 1\) و \(f(r_{k+1}) = n\):

\[\sum_{t\ \text{odd}}\big(f(r_{t+1}) - f(r_{t-1}) + 1\big) \le n + k,\]

چون بازه‌ها پشت سر هم‌اند و جمع طولشان تلسکوپی است. پس \(T(k) = T(k/2) + O(k + n)\). با باز کردن: \(\sum_{d \ge 0}(k/2^d + n)\) روی \(\lg k + 1\) سطح، یعنی \(O(m + n\log m)\).

آرایهٔ \(A[i, j] = (2i - j)^2 + j\) (برای \(i = 1..5\) و \(j = 1..6\)) مونژ است. کمینهٔ چپ هر سطر پررنگ شده:

  • اگر «جای بهترین جواب» یکنوا باشد (\(f(i) \le f(i+1)\))، نیمی از سطرها را بازگشتی حل کن و بقیه را بین همسایه‌ها بگرد؛ جمع پیمایش‌ها تلسکوپی و خطی است.
  • یکنوایی را با فرض خلف روی دو سطر مجاور و دو ستون مشکوک ثابت کن؛ تعریف «چپ‌ترین» نامساوی اکید لازم را می‌دهد.
  • این ایده پایهٔ بهینه‌سازی‌های معروف برنامه‌نویسی پویاست (نامساوی چهارضلعی).

متوسطتقسیم و حلمرتب‌سازی ادغامیجزوه: فصل ۲

چرا «متوسط»؟ اگر شمردن وارونه‌ها با ادغام را بلد باشید سرراست است؛ نکتهٔ ظریف، شمارش جدا از ادغام است.

ایده‌های این مسئله در ایده‌نامه: ۲.۲ جواب = چپ + راست + آنچه از مرز می‌گذرد، ۲.۳ دو اشاره‌گر روی دو فهرست مرتب، ۲.۴ از بازگشت بیشتر بخواه، ۹.۸ وارونه‌ها: معیار نامرتبی

الگوریتمی ارائه دهید که در \(O(n\log n)\) تعداد جفت‌های \((i, j)\) را پیدا کند که \(i < j\) و \(A[i] > 2A[j]\).

مثل شمردن وارونه‌ها با مرتب‌سازی ادغامی: هر جفت یا کاملاً در نیمهٔ چپ است، یا کاملاً در راست، یا یکی در هر نیمه. حالت سوم را روی دو نیمهٔ مرتب‌شده با دو اشاره‌گر بشمارید؛ ولی شمارش را جدا از ادغام انجام دهید.

راه‌حل کامل مرور درس، حل گام‌به‌گام و جمع‌بندی
شمردن وارونه‌ها با ادغام

جفت \((i, j)\) با \(i\) در نیمهٔ چپ و \(j\) در نیمهٔ راست همیشه \(i < j\) دارد؛ پس برای این جفت‌ها ترتیب داخل هر نیمه دیگر مهم نیست و می‌توانیم نیمه‌ها را مرتب کنیم. روی دو فهرست مرتب، شرط‌های یکنوا را با دو اشاره‌گر در زمان خطی می‌شمارند. رابطهٔ زمان \(T(n) = 2T(n/2) + O(n) = O(n\log n)\).

الگوریتم

if |A| <= 1
    return (A, 0)
(L, x) = SORT-AND-COUNT(left half of A)
(R, y) = SORT-AND-COUNT(right half of A)
z = 0; j = 0
for each a in L                      // L and R are sorted ascending
    while j < |R| and a > 2 * R[j]
        j = j + 1
    z = z + j                        // a > 2*R[0..j-1]
return (MERGE(L, R), x + y + z)

چرا درست است؟

  • سه نوع جفت: داخل چپ (\(x\))، داخل راست (\(y\)) و جفت‌های بین دو نیمه (\(z\)). هیچ جفتی دو بار یا جا نمی‌افتد.
  • دو اشاره‌گر: برای \(a\) ثابت، مجموعهٔ \(\{r \in R : 2r < a\}\) یک پیشوند از \(R\) مرتب است؛ و با بزرگ شدن \(a\) این پیشوند فقط بلندتر می‌شود. پس \(j\) هیچ‌وقت عقب نمی‌رود و کل حلقه \(O(|L| + |R|)\) است. (برای اعداد منفی هم درست است.)
  • چرا شمارش جدا از ادغام؟ مقایسهٔ ادغام \(a > r\) است ولی شرط ما \(a > 2r\)؛ این دو در یک گذر با هم جور نمی‌شوند. یک گذر اضافهٔ خطی هزینه را عوض نمی‌کند.
ردیابی برای \(A = [2, 4, 3, 5, 1]\)
  • نیمهٔ چپ \([2, 4]\): بین \([2]\) و \([4]\)، \(2 > 8\)؟ نه. \(x = 0\).
  • نیمهٔ راست \([3, 5, 1]\): اول \([5]\) و \([1]\): \(5 > 2\)، یک جفت. بعد \([3]\) با \([1, 5]\): \(3 > 2\)، یک جفت. \(y = 2\).
  • بالاترین سطح: \(L = [2, 4]\)، \(R = [1, 3, 5]\). برای \(a = 2\): \(2 > 2\)؟ نه، \(j = 0\). برای \(a = 4\): \(4 > 2\) پس \(j = 1\)؛ \(4 > 6\)؟ نه. \(z = 1\).

جمع: \(0 + 2 + 1 = 3\). جفت‌ها: \((4, 1)\)، \((3, 1)\) و \((5, 1)\). (این الگوریتم با جست‌وجوی کامل روی صدها آرایهٔ تصادفی بررسی شده است.)

  • «شمردن جفت‌های \(i < j\) با یک شرط روی مقدارها» ⇐ تقسیم و حل: شرط \(i < j\) به «چپ در برابر راست» تبدیل می‌شود و داخل هر نیمه آزادیم مرتب کنیم.
  • روی دو نیمهٔ مرتب، اگر شرط یکنوا باشد، با دو اشاره‌گر خطی بشمار. اگر شرط با مقایسهٔ ادغام فرق دارد، شمارش را در گذر جداگانه انجام بده.
  • هر کار اضافهٔ خطی در هر سطح، کل زمان را \(O(n\log n)\) نگه می‌دارد.

سختاستقراکاشی‌کاریجزوه: فصل ۲

چرا «سخت»؟ ایدهٔ «خانه‌های گوشه» کلید مسئله است؛ بدون آن، اثبات اینکه فقط \(n = 2^k - 1\) جواب می‌دهد سخت است.

ایده‌های این مسئله در ایده‌نامه: ۰.۱ مثال کوچک بساز، ۰.۷ به حدی‌ترین شیء نگاه کن، ۰.۸ خانه‌های خاص و لانهٔ کبوتر، ۰.۹ به نمونهٔ کوچک‌ترِ همان مسئله برسان

یک «پلهٔ مثلثی» \(S(n)\) داریم که سطر اول آن \(n\) خانه، سطر دوم \(n - 1\) خانه، … و سطر \(n\)ام فقط ۱ خانه دارد؛ یعنی شکلی پلکانی و راست‌گوشه روی شبکهٔ مربعی. می‌خواهیم بررسی کنیم آیا می‌توان این پله را دقیقاً با \(n\) مربع با اضلاع صحیح، بدون هم‌پوشانی و دقیقاً روی شبکه، کاشی‌کاری کرد یا نه. اگر امکان‌پذیر بود، یک راه‌حل بازگشتی ارائه دهید و مقادیر \(n\) را بیابید که بتوان این کار را انجام داد.

به \(n\) خانهٔ «گوشه» نگاه کنید (آخرین خانهٔ هر سطر). آیا یک مربع می‌تواند دو خانهٔ گوشه را بپوشاند؟ نتیجه بگیرید هر مربع دقیقاً یک گوشه دارد. بعد ببینید خانهٔ بالا-چپ را کدام مربع می‌تواند بپوشاند.

راه‌حل کامل مرور درس، حل گام‌به‌گام و جمع‌بندی
اصل لانهٔ کبوتری و عنصر حدی

دو ابزار کلاسیک مسئله‌های کاشی‌کاری: (۱) خانه‌های خاصی پیدا کن که هیچ دوتایشان در یک قطعه نمی‌گنجند؛ اگر تعدادشان با تعداد قطعه‌ها برابر باشد، هر قطعه دقیقاً یکی را دارد. (۲) به خانهٔ حدی (گوشهٔ شکل) نگاه کن؛ قطعه‌ای که آن را می‌پوشاند معمولاً اجباری است. بعد مسئلهٔ باقی‌مانده را با استقرا حل کن.

سطرها را از بالا ۱ تا \(n\) و ستون‌ها را از چپ شماره می‌زنیم؛ سطر \(i\) ستون‌های ۱ تا \(n - i + 1\) را دارد. خانهٔ گوشهٔ سطر \(i\) را \(c_i = (i,\ n - i + 1)\) می‌نامیم.

۱هر مربع دقیقاً یک گوشه دارد

اگر مربعی دو گوشهٔ \(c_i\) و \(c_k\) (با \(i < k\)) را بپوشاند، چون مربع (و هر مستطیل) هر خانه‌ای بین سطرها و ستون‌هایش را دارد، خانهٔ \((k,\ n - i + 1)\) را هم می‌پوشاند. اما سطر \(k\) فقط تا ستون \(n - k + 1 < n - i + 1\) ادامه دارد؛ این خانه بیرون شکل است. پس هیچ مربعی دو گوشه ندارد. \(n\) گوشه و \(n\) مربع داریم، پس هر مربع دقیقاً یک گوشه را می‌پوشاند.

به‌علاوه \(c_i\) آخرین خانهٔ سطرش و پایین‌ترین خانهٔ ستونش است، پس مربعِ آن نمی‌تواند به راست یا پایین \(c_i\) برود: \(c_i\) گوشهٔ پایین-راست مربع خودش است.

۲مربع خانهٔ بالا-چپ اجباری است

خانهٔ \((1, 1)\) را مربعی با گوشهٔ \(c_i\) و ضلع \(s\) پوشانده است. این مربع سطرهای \(i - s + 1..i\) و ستون‌های \(n - i + 2 - s..n - i + 1\) را دارد. برای رسیدن به سطر ۱ باید \(s = i\) و برای رسیدن به ستون ۱ باید \(s = n - i + 1\). پس \(i = n - i + 1\)، یعنی \(n = 2i - 1\) فرد است و یک مربع \(\frac{n+1}{2} \times \frac{n+1}{2}\) در گوشهٔ بالا-چپ قرار دارد.

۳آنچه می‌ماند دو پلهٔ کوچک‌تر است

با \(n = 2m + 1\)، بعد از برداشتن مربع \((m+1) \times (m+1)\)، دو تکه می‌ماند: سمت راست (سطرهای ۱ تا \(m\)) و پایین (سطرهای \(m + 2\) تا \(2m + 1\))، که هر دو دقیقاً \(S(m)\)اند و به هم نمی‌چسبند. هر مربع باقی‌مانده یکپارچه است، پس تمامش در یکی از دو تکه است؛ و هر تکه \(m\) گوشه دارد، پس با دقیقاً \(m\) مربع کاشی شده است.

۴نتیجه

با استقرا: \(S(n)\) با \(n\) مربع کاشی می‌شود اگر و تنها اگر \(n = 2m + 1\) و \(S(m)\) با \(m\) مربع کاشی شود (\(S(0)\) تهی و \(S(1)\) یک مربع است). پس \(n = 2^k - 1\) یعنی \(1, 3, 7, 15, \dots\)، و کاشی‌کاری در هر حالت یکتا است. (جست‌وجوی کامل با برنامه برای \(n = 1..8\) تعداد کاشی‌کاری‌ها را \(1, 0, 1, 0, 0, 0, 1, 0\) داد.) 

if m == 0
    return
k = (m + 1) / 2
place a k x k square with top-left cell (r, c)
TILE(r, c + k, k - 1)        // the staircase to the right
TILE(r + k, c, k - 1)        // the staircase below

تعداد مربع‌ها \(Q(m) = 1 + 2Q\big(\frac{m-1}{2}\big)\) و \(Q(0) = 0\)، که دقیقاً \(Q(m) = m\) می‌دهد.

  • خانه‌های خاص: خانه‌هایی پیدا کن که هیچ دوتایشان در یک قطعه نیستند. اگر تعدادشان برابر تعداد قطعه‌ها باشد، ساختار قطعه‌ها قفل می‌شود.
  • خانهٔ حدی: قطعه‌ای که گوشهٔ شکل را می‌پوشاند را تحلیل کن؛ اغلب اجباری است و شرط لازمی (مثل فرد بودن \(n\)) بیرون می‌دهد.
  • استقرا: بعد از قطعهٔ اجباری، باقی‌مانده نمونه‌های کوچک‌تر همان مسئله است. ساخت بازگشتی همان اثبات کافی بودن است.

متوسطاستقرامجموع پیشوندی

چرا «متوسط»؟ مسئلهٔ کلاسیک؛ ایدهٔ «بعد از کمینه شروع کن» را که ببینید، اثبات چند خط است.

ایده‌های این مسئله در ایده‌نامه: ۰.۷ به حدی‌ترین شیء نگاه کن، ۱.۱۲ مجموع پیشوندی

میزان بنزینی که ماشین برای یک دور کامل یک مسیر دایره‌ای لازم دارد، بین \(n\) پمپ‌بنزین روی این مسیر تقسیم شده است. ثابت کنید نقطه‌ای روی دایره هست که ماشین با باک خالی، با شروع از آن نقطه، می‌تواند کل مسیر را طی کند (ظرفیت باک را به اندازهٔ کافی بزرگ فرض کنید).

تصور کنید ماشین با کمی بنزین قرضی از یک نقطهٔ دلخواه شروع کند و نمودار «بنزین داخل باک» را در طول مسیر بکشید. این نمودار کجا کمترین مقدار را دارد؟ اگر از همان نقطه شروع کنید، نمودار فقط بالا و پایین جابه‌جا می‌شود.

مجموع پیشوندی

برای دنبالهٔ \(d_1, \dots, d_n\)، مجموع پیشوندی \(P_k = d_1 + \dots + d_k\) و \(P_0 = 0\). جمع هر بازهٔ متوالی، تفاضل دو مجموع پیشوندی است: \(d_s + \dots + d_k = P_k - P_{s-1}\).

مدل

پمپ‌ها را به ترتیب حرکت \(1, \dots, n\) بنامید. پمپ \(i\) مقدار \(g_i\) بنزین دارد و رفتن از پمپ \(i\) به پمپ بعدی \(c_i\) بنزین مصرف می‌کند. طبق فرض \(\sum g_i = \sum c_i\). بگذارید \(d_i = g_i - c_i\)، پس \(\sum d_i = 0\) و \(P_n = 0\).

انتخاب نقطهٔ شروع

اندیس \(s - 1 \in \{0, \dots, n-1\}\) را طوری بگیرید که \(P_{s-1}\) کمینه باشد، و از پمپ \(s\) شروع کنید. بنزین باک بعد از رسیدن به پمپ بعد از \(k\):

  • اگر \(k \ge s\): برابر \(d_s + \dots + d_k = P_k - P_{s-1} \ge 0\).
  • اگر دور زده‌ایم (\(k < s - 1\)): برابر \((P_n - P_{s-1}) + P_k = P_k - P_{s-1} \ge 0\)، چون \(P_n = 0\).

در هر دو حالت باک هیچ‌وقت منفی نمی‌شود، پس ماشین کل دور را طی می‌کند. ∎

اثبات دوم: استقرا روی \(n\)

دست‌کم یک پمپ \(i\) با \(g_i \ge c_i\) هست (وگرنه \(\sum g < \sum c\)). پمپ \(i + 1\) را در پمپ \(i\) ادغام کنید: بنزین \(g_i + g_{i+1}\) و مسیر تا پمپ \(i + 2\) با مصرف \(c_i + c_{i+1}\). مسئلهٔ جدید \(n - 1\) پمپ دارد و طبق استقرا نقطهٔ شروعی دارد. همان نقطه در مسئلهٔ اصلی هم کار می‌کند: وقتی به پمپ \(i\) می‌رسیم، چون \(g_i \ge c_i\)، به پمپ \(i + 1\) هم می‌رسیم و بنزینش را برمی‌داریم.

این اثبات یک الگوریتم \(O(n)\) هم می‌دهد: یک بار \(P_k\)ها را حساب کن و بعد از کمینه شروع کن.

  • مسئله‌های «دنبالهٔ دوری با جمع صفر» ⇐ مجموع پیشوندی؛ بعد از کمینهٔ کلی شروع کن تا همهٔ جمع‌های جزئی نامنفی شوند (لم چرخه).
  • اثبات وجودی را می‌توان با عنصر حدی (کمینه) یا با استقرا و ادغام دو عنصر انجام داد؛ اولی الگوریتم خطی هم می‌دهد.

صفحهٔ شطرنجی

سختشمارشاستقرا

چرا «سخت»؟ سه مشاهدهٔ پشت سر هم لازم است: مساحت‌ها \(1..n\)اند، هر مستطیل یک خانهٔ قطری دارد، و \(k(n-k+1) \ge n\).

ایده‌های این مسئله در ایده‌نامه: ۰.۱ مثال کوچک بساز، ۰.۷ به حدی‌ترین شیء نگاه کن، ۰.۸ خانه‌های خاص و لانهٔ کبوتر، ۰.۹ به نمونهٔ کوچک‌ترِ همان مسئله برسان

یک صفحهٔ شطرنجی \(n \times n\) را در نظر بگیرید که همهٔ خانه‌های بالای قطر اصلی آن حذف شده‌اند. به چند طریق می‌توان شکل حاصل را با \(n\) مستطیل با مساحت‌های مختلف پوشاند، به‌طوری‌که اضلاع هر مستطیل روی خطوط صفحه باشند؟

مساحت کل \(\frac{n(n+1)}{2}\) است؛ \(n\) عدد مثبت متمایز با این جمع دقیقاً کدام‌اند؟ مثل مسئلهٔ ۱۴، خانه‌های روی قطر را بررسی کنید. بعد ببینید مستطیلی که خانهٔ گوشهٔ پایین-چپ را می‌پوشاند چه شکلی می‌تواند داشته باشد.

راه‌حل کامل مرور درس، حل گام‌به‌گام و جمع‌بندی
همان ابزار مسئلهٔ ۱۴

خانه‌های خاصی که دوتایشان در یک قطعه نمی‌گنجند، به‌علاوهٔ قطعه‌ای که گوشهٔ حدی را می‌پوشاند. تنها فرق: این‌جا به‌جای وجود، تعداد راه‌ها را می‌شمریم؛ استقرا به رابطهٔ بازگشتی تبدیل می‌شود.

سطرها را از بالا ۱ تا \(n\) شماره می‌زنیم؛ سطر \(i\) خانه‌های ستون ۱ تا \(i\) را دارد (یک پلکان با \(\frac{n(n+1)}{2}\) خانه).

۱مساحت‌ها دقیقاً \(1, 2, \dots, n\)اند

\(n\) عدد صحیح مثبت متمایز دست‌کم \(1 + 2 + \dots + n = \frac{n(n+1)}{2}\) جمع دارند و تساوی فقط برای خود \(\{1, \dots, n\}\) رخ می‌دهد. جمع مساحت‌ها دقیقاً همین است، پس مساحت‌ها \(1, 2, \dots, n\) هستند. یعنی هیچ مستطیلی بیشتر از \(n\) خانه ندارد.

۲هر مستطیل دقیقاً یک خانهٔ قطری دارد

خانه‌های قطری \((i, i)\) را در نظر بگیرید. اگر مستطیلی \((i, i)\) و \((k, k)\) با \(i < k\) را داشت، خانهٔ \((i, k)\) (بالای قطر) را هم داشت که حذف شده است. \(n\) خانهٔ قطری و \(n\) مستطیل: هر مستطیل دقیقاً یکی دارد، و آن خانه گوشهٔ بالا-راست مستطیل است (سمت راست و بالای آن بیرون شکل است).

۳مستطیل گوشهٔ پایین-چپ فقط دو حالت دارد

مستطیلی که خانهٔ \((n, 1)\) را دارد، گوشهٔ بالا-راستش یک خانهٔ قطری \((k, k)\) است؛ پس سطرهای \(k..n\) و ستون‌های \(1..k\) را می‌گیرد و مساحتش

\[k(n - k + 1) = n + (k - 1)(n - k) \ge n.\]

چون هیچ مساحتی از \(n\) بیشتر نیست، باید \((k - 1)(n - k) = 0\): یا \(k = 1\) (کل ستون اول، \(n \times 1\)) یا \(k = n\) (کل سطر آخر، \(1 \times n\)).

۴رابطهٔ بازگشتی

در هر دو حالت آنچه می‌ماند یک پلکان با اندازهٔ \(n - 1\) است که باید با \(n - 1\) مستطیل با مساحت‌های متمایز (یعنی \(1..n-1\)) پوشانده شود: همان مسئله. برعکس، هر پوشش پلکان \(n - 1\) به‌علاوهٔ نوار انتخابی، پوشش درستی برای \(n\) است. برای \(n \ge 2\) دو انتخاب متفاوت‌اند. پس اگر \(a_n\) تعداد راه‌ها باشد:

\[a_1 = 1,\qquad a_n = 2a_{n-1}\quad\Longrightarrow\quad a_n = 2^{n-1}.\]

جواب: \(2^{n-1}\) راه. (شمارش کامل با برنامه برای \(n = 1..6\): \(1, 2, 4, 8, 16, 32\).)

  • «\(n\) عدد متمایز با جمعِ کمینهٔ ممکن» یعنی دقیقاً \(\{1, \dots, n\}\)؛ این شرط سقف اندازهٔ قطعه‌ها را می‌دهد.
  • برای شمردن پوشش‌ها، قطعهٔ گوشهٔ حدی را تحلیل کن؛ تعداد حالت‌هایش ضریب رابطهٔ بازگشتی است (این‌جا ۲).
  • نامساوی کلیدی \(k(n - k + 1) \ge n\) با تساوی فقط در دو سر؛ این نوع نامساوی (حاصل‌ضرب دو عدد با جمع ثابت) زیاد به کار می‌آید.
