# جزوهٔ ساختمان داده‌ها و الگوریتم‌ها

جزوهٔ کامل فارسی (راست‌به‌چپ) درس ساختمان داده‌ها و الگوریتم‌ها، ساخته‌شده از روی اسلایدهای درس، با توضیح کامل مفاهیم، اثبات‌ها، مثال‌های حل‌شده، شکل‌ها و خودآزمایی.

## نسخهٔ آنلاین

- **https://iamhirad.github.io/Abam/** — نسخهٔ وب روی GitHub Pages
- **https://iamhirad.github.io/Abam/jozve-dsa.pdf** — دانلود PDF

## فایل‌های آماده

- [`jozve/dist/jozve-dsa.pdf`](jozve/dist/jozve-dsa.pdf) — نسخهٔ PDF برای چاپ و مطالعه (A4)
- [`jozve/dist/jozve-dsa.html`](jozve/dist/jozve-dsa.html) — نسخهٔ وب، یک فایل مستقل که بدون اینترنت هم باز می‌شود (حالت روشن و تیره)

## فصل‌ها

1. طراحی و تحلیل الگوریتم‌ها — مرتب‌سازی درجی، نمادهای O و Ω و Θ، فیبوناچی، زیرآرایهٔ بیشینه، زمان‌های اجرای رایج
2. تقسیم و حل — مرتب‌سازی ادغامی، درخت بازگشت، قضیهٔ اصلی، ضرب کاراتسوبا، روش حدس و استقرا
3. الگوریتم‌های تصادفی — احتمال و امید ریاضی، میانهٔ تقریبی، مونت‌کارلو و لاس‌وگاس، مسئلهٔ استخدام، انتخاب، کوئیک‌سورت
4. تحلیل سرشکنی — پشته با multipop، شمارندهٔ دودویی، روش‌های انبوهه، حساب‌داری و پتانسیل، آرایهٔ پویا
5. آرایه، لیست پیوندی، پشته و صف — نوع دادهٔ انتزاعی، لیست یک‌طرفه و دوطرفه، معکوس‌کردن لیست، تشخیص دور فلوید، مسئلهٔ ژوزفوس، پشته و کاربردهایش (پرانتزها، نزدیک‌ترین عنصر بزرگ‌تر، جایگشت قطار)، صف حلقوی
6. درخت — تعریف‌ها، ارتفاع و عمق، درخت kتایی و نمایش فرزند چپ/برادر راست، پیمایش‌های پیش‌ترتیب و پس‌ترتیب و میان‌ترتیب، بازسازی درخت از پیمایش‌ها
7. درخت عبارت — گرامر عبارت‌ها، نگارش میانوندی و پیشوندی و پسوندی، ارزیابی با پشته، ساخت درخت از عبارت در O(n)، الگوریتم دو پشته با اولویت عملگرها
8. هرم و صف اولویت — هرم بیشینه و کمینه، نمایش آرایه‌ای، افزایش کلید، درج و حذف، ساخت هرم در O(n)، شمارش عناصر بزرگ‌تر از k، مرتب‌سازی هرمی
9. کران پایین مرتب‌سازی و مرتب‌سازی خطی — درخت تصمیم، کران Ω(n log n)، مرتب‌سازی شمارشی، پایداری، مرتب‌سازی مبنایی
10. درخت ترای (trie) — مسئلهٔ لغت‌نامه، ساختار گره و پرچم پایان کلمه، جست‌وجو و درج و حذف در O(m)، حافظه، ترای فشرده، کاربردها
- پیوست — برگهٔ فرمول‌ها، جدول الگوریتم‌ها، واژه‌نامه و منابع

## ساخت دوباره

متن جزوه در `jozve/src` است (هر فصل یک فایل HTML، فرمول‌ها با `\( ... \)` و `\[ ... \]`) و شکل‌ها در `jozve/figures.mjs`، `jozve/figures2.mjs` و `jozve/figures3.mjs` ساخته می‌شوند.

```bash
cd jozve
npm install
node build.mjs          # فقط HTML
node build.mjs --pdf    # HTML و PDF (نیازمند Playwright و Chromium)
```
