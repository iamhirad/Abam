# جزوهٔ ساختمان داده‌ها و الگوریتم‌ها

جزوهٔ کامل فارسی (راست‌به‌چپ) درس ساختمان داده‌ها و الگوریتم‌ها، ساخته‌شده از روی اسلایدهای درس، با توضیح کامل مفاهیم، اثبات‌ها، مثال‌های حل‌شده، شکل‌ها و خودآزمایی.

## فایل‌های آماده

- [`jozve/dist/jozve-dsa.pdf`](jozve/dist/jozve-dsa.pdf) — نسخهٔ PDF برای چاپ و مطالعه (A4)
- [`jozve/dist/jozve-dsa.html`](jozve/dist/jozve-dsa.html) — نسخهٔ وب، یک فایل مستقل که بدون اینترنت هم باز می‌شود (حالت روشن و تیره)

## فصل‌ها

1. طراحی و تحلیل الگوریتم‌ها — مرتب‌سازی درجی، نمادهای O و Ω و Θ، فیبوناچی، زیرآرایهٔ بیشینه، زمان‌های اجرای رایج
2. تقسیم و حل — مرتب‌سازی ادغامی، درخت بازگشت، قضیهٔ اصلی، ضرب کاراتسوبا، روش حدس و استقرا
3. الگوریتم‌های تصادفی — احتمال و امید ریاضی، میانهٔ تقریبی، مونت‌کارلو و لاس‌وگاس، مسئلهٔ استخدام، انتخاب، کوئیک‌سورت
4. تحلیل سرشکنی — پشته با multipop، شمارندهٔ دودویی، روش‌های انبوهه، حساب‌داری و پتانسیل، آرایهٔ پویا
- پیوست — برگهٔ فرمول‌ها، جدول الگوریتم‌ها، واژه‌نامه و منابع

## ساخت دوباره

متن جزوه در `jozve/src` است (هر فصل یک فایل HTML، فرمول‌ها با `\( ... \)` و `\[ ... \]`) و شکل‌ها در `jozve/figures.mjs` ساخته می‌شوند.

```bash
cd jozve
npm install
node build.mjs          # فقط HTML
node build.mjs --pdf    # HTML و PDF (نیازمند Playwright و Chromium)
```
